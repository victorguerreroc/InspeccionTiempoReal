Power Query — conectar KPI Excel automáticamente

Copia cada bloque de código en Excel → Datos → Obtener datos → Consulta en blanco → Editor avanzado.
Las consultas leen lotes.json y srfi.json directo de tu carpeta OneDrive y actualizan el KPI con un clic.

⚠ Selecciona primero la carpeta de SharePoint para generar el código con la ruta correcta.
Query 1 — Lotes QC 
Selecciona la carpeta primero.
Query 2 — SRFI / Desviaciones 
Selecciona la carpeta primero.
Query 3 — FPY Mensual (para el KPI) 
Selecciona la carpeta primero.
Query 4 — Inspección en Proceso (pieza por pieza) 
Selecciona la carpeta primero.

Pega la ruta de la carpeta que seleccionaste. La encuentras en el Explorador de Windows → barra de dirección.

📖 Ver instrucciones paso a paso
  1. Abre el archivo KPI 2026.xlsm en Excel
  2. Ve a Datos → Obtener datos → Desde otras fuentes → Consulta en blanco
  3. En el Editor de Power Query, ve a Inicio → Editor avanzado
  4. Borra todo el texto y pega el código de Query 1 — Lotes QC
  5. Haz clic en Listo y nombra la consulta LotesQC
  6. Repite los pasos 2-5 para Query 2 (SRFI) y Query 3 (FPY)
  7. Cierra el Editor y elige Cargar en → Tabla en hoja existente
  8. Para actualizar: Datos → Actualizar todo (o Ctrl+Alt+F5)

💡 Puedes programar la actualización automática en Datos → Propiedades de la conexión → Actualizar cada X minutos.
